# PMS 通用属性映射规则原型设计

## 1. 目标

将运营端现有的“PMS 版本映射规则”调整为通用的“PMS 属性映射规则”。版本只是 PMS 属性项 PPN 的一种，运营端必须能够为同一商品选择不同属性项 PPN，并配置该属性项下源属性值 PPV 到目标属性值 PPV 的映射。

本文档取代 `2026-08-30-pms-version-mapping-design.md` 中关于运营端映射模块的设计。价格能力不属于本次范围，将由单独需求定义。

## 2. 范围

本次仅修改 `platform.html` 的商品映射管理模块及对应契约测试。

- 删除该模块中的海外价格系数、MYR 固定调整值及相关价格文案、数据、列表列、校验和中英文翻译。
- 将“版本 PPN / 版本 PPV”统一改为“属性项 PPN / 属性值 PPV”。
- 同一商品支持多个 PMS 属性项 PPN。
- `store.html` 保持字节级不变。
- 不修改平台其他财务、结算、竞拍价格快照等既有模块。

## 3. 页面信息架构

- 二级菜单：`PMS 属性映射规则`
- 页面标题：`PMS 属性映射转化规则`
- 新增按钮：`新增映射规则`
- 顶部说明：商品、属性项 PPN、源属性值 PPV 和目标属性值 PPV 均来自 PMS；海外系统只选择 PMS 返回值，不自建 PPN/PPV，也不直接配置目标 `skuId`。

筛选项包括：

- 站点
- 商品 / 型号
- 源属性值 PPV
- 目标属性值 PPV
- 状态

规则列表包括：

- 映射编号 / 版本
- 站点 / 商品
- 属性项 PPN 名称 / ID
- 源属性值 PPV 名称 / ID
- 目标属性值 PPV 名称 / ID
- PMS 校验
- 状态
- 更新人 / 时间
- 操作

## 4. 新增与编辑规则

表单字段为：

- 站点
- 商品 / 型号
- 属性项 PPN
- 源属性值 PPV
- 目标属性值 PPV
- 状态
- 变更原因

级联顺序：

1. 选择商品后，加载 PMS 返回的该商品全部属性项 PPN。
2. 选择属性项 PPN 后，源、目标属性值下拉框只展示该 PPN 下的 PPV。
3. 编辑既有规则时，按商品、PPN、源 PPV、目标 PPV 回显。

原型数据至少为一个商品提供两个 PPN，用于证明能力不是版本专用。例如：

- 销售地区 / 版本：马来版本、海外其他版本、国行版本。
- 购买渠道：香港零售、大陆国行、海外版本。

## 5. 数据与校验

PMS 目录按“商品 → 多个 PPN → 每个 PPN 下多个 PPV”组织。映射规则只保存 PMS 标识和展示名称，不保存价格字段。

保存顺序：

1. 所选 PPN 必须属于当前商品的 PMS 属性目录。
2. 源 PPV、目标 PPV 必须属于所选 PPN。
3. 目标 PPV 必须能够与商品其他属性组成合法 SKU。
4. 变更原因必填。
5. 同一时点，“站点＋商品＋属性项 PPN＋源属性值 PPV”只能存在一条生效规则。

未命中、非法或重复时阻止保存，不做静默兜底。

## 6. 中英文与验收

新增可见文案必须支持中英文切换，切换语言不得改变当前路由或规则数据。

验收标准：

- 映射模块内不再出现价格系数、固定调整值或价格策略文案。
- 页面和弹窗不再将 PPN/PPV 限定为版本。
- 同一商品可切换至少两个属性项 PPN，PPV 随 PPN 正确联动。
- 筛选、新增、编辑、停用、启用、历史版本入口正常。
- 唯一性和 PMS 归属校验正常。
- `store.html` 与修改前 SHA-256 一致。
