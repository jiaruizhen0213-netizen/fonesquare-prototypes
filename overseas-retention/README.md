# 海外留货原型：指定物品留货

基于原需求文档附件《海外留货与采购需求管理系统原型-已更新.html》扩展。

- 原“留货策略”菜单更名为“指定策略留货”，下方新增“指定物品留货”。
- Excel 按物品编号、国家/地区导入，提交后直接执行，无解析预览或二次确认。
- 指定物品留货首页直接展示逐物品明细，支持按物品编号、国家/地区和留货结果查询、导出。
- 留货结果为待锁、成功、失败；每次上传仅以简短弹窗展示本次数量汇总，逐件结果与失败原因在首页查看，同时同步展示于留货明细。
- 商品信息优先使用留货库存，未命中时模拟 PMS 补充；PMS 来源的快照时间、货源主体、运营中心显示“—”，导出为空。
- 原型使用本地模拟数据，不连接真实 PMS、银河，不会实际锁货。导入记录保存在当前浏览器本地。

打开 `index.html#specifiedItems` 进入新增页面。可直接下载 HTML 离线打开，Excel 读写库已内嵌。

- `import-template.xlsx`：空白导入模板。
- `import-example.xlsx`：可演示库存命中、PMS 补充与失败结果的示例文件。

浏览器交互验证覆盖模板下载、混合地区导入、结果状态、字段留空及导出、明细联动、重复编号与重复提交、错误模板、记录持久化和原有页面导航。

## 留货明细字段对齐（2026-09-21）

`index.html#stayDetails` 按实际系统 `/details` 展示 25 列：商品码、物品编码、货源主体、运营中心、型号名称、内存、颜色、海外购买渠道、海外等级、PJT等级、质检报告编号、最新看图成色、边框背板、屏幕外观、屏幕显示、电池健康度、海外结算价、预估售价、单台预估利润率、平均结算价、平均预估利润率、命中策略、比货留货时间、留货结果、失败原因。

- 筛选为留货时间、型号、内存、颜色、海外购买渠道、海外等级、运营中心、物品编号、命中策略、留货结果。默认查询今日，每页 20 条。
- 商品码打开 27 项明细详情，其中额外展示运行批次和策略执行。无商品码的指定物品失败记录可点击物品编码查看详情。
- 金额合并展示币种，计算失败原因展示在对应数值下；主明细导出同样采用这 25 列并包含币种和原因。
- 策略成功数达到目标后才计算平均结算价、平均预估利润率，使用该策略全部成功明细，不随列表筛选改变。演示数据遇到缺值时不对部分明细求平均，展示无法计算的明细数量和原因；这项缺值处理仅为原型演示规则。
- 模拟策略覆盖：iPhone 13 已达标但有缺少售价的成功明细；iPhone 15 已达标且可计算全部平均值；iPhone 15 Pro 有成功明细但尚未达标。
- 原内部字段保留供指定物品流程使用。PJT 等级使用独立模拟值或已有库存字段，策略执行使用独立模拟标识；指定物品记录的运行批次和策略执行留空，不把导入批次或计算结果关联键当作同一字段。
- 指定物品页面的 Excel 导入、导出和详情，以及留货库存页面沿用原结构。指定物品记录继续同步至主明细，策略平均值显示不适用原因。
