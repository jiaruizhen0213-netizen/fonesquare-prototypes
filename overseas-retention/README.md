# 海外留货原型：指定物品留货

基于原需求文档附件《海外留货与采购需求管理系统原型-已更新.html》扩展。

- 原“留货策略”菜单更名为“指定策略留货”，下方新增“指定物品留货”。
- Excel 按物品编号、国家/地区导入，提交后直接执行，无解析预览或二次确认。
- 指定物品留货首页仅展示物品编号、国家/地区、留货结果、失败原因、操作人、留货时间、锁货处理时间 7 列，支持按物品编号、国家/地区和留货结果查询。导出包含这 7 列及原始行号。
- 点击物品编号前往留货明细，自动按该编号筛选并清除原有筛选条件（含时间范围），可查看商品与质检信息。
- 留货结果为待锁、成功、失败；每次上传仅以简短弹窗展示本次数量汇总，逐件结果与失败原因在首页查看，同时同步展示于留货明细。
- 商品信息优先使用留货库存，未命中时模拟 PMS 补充；信息保留并同步至留货明细，PMS 未提供的快照时间、货源主体、运营中心留空。
- 原型使用本地模拟数据，不连接真实 PMS、银河，不会实际锁货。导入记录保存在当前浏览器本地。

打开 `index.html#specifiedItems` 进入新增页面。可直接下载 HTML 离线打开，Excel 读写库已内嵌。

- `import-template.xlsx`：空白导入模板。
- `import-example.xlsx`：可演示库存命中、PMS 补充与失败结果的示例文件。

浏览器交互验证覆盖模板下载、混合地区导入、结果状态、字段留空及导出、明细联动、重复编号与重复提交、错误模板、记录持久化和原有页面导航。

## 留货明细字段对齐（2026-09-21）

`index.html#stayDetails` 按实际系统 `/details` 展示 25 列：商品码、物品编码、货源主体、运营中心、型号名称、内存、颜色、海外购买渠道、海外等级、PJT等级、质检报告编号、最新看图成色、边框背板、屏幕外观、屏幕显示、电池健康度、海外结算价、预估售价、单台预估利润率、平均结算价、平均预估利润率、命中策略、比货留货时间、留货结果、失败原因。

- 筛选为留货时间、型号、内存、颜色、海外购买渠道、海外等级、运营中心、物品编号、命中策略、留货结果。默认查询今日，每页 20 条。
- 商品码打开 27 项明细详情，其中额外展示运行批次和策略执行。无商品码的指定物品失败记录可点击物品编码查看详情。
- 金额合并展示币种，计算失败原因展示在对应数值下；主明细导出同样采用这 25 列并包含币种和原因。
- 策略成功数达到目标后才计算平均结算价、平均预估利润率，使用该策略全部成功明细，不随列表筛选改变。演示数据遇到缺值时不对部分明细求平均，展示无法计算的明细数量和原因；这项缺值处理仅为原型演示规则。
- 模拟策略覆盖：iPhone 13 已达标但有缺少售价的成功明细；iPhone 15 已达标且可计算全部平均值；iPhone 15 Pro 有成功明细但尚未达标。
- 原内部字段保留供指定物品流程使用。PJT 等级使用独立模拟值或已有库存字段，策略执行使用独立模拟标识；指定物品记录的运行批次和策略执行留空，不把导入批次或计算结果关联键当作同一字段。
- 指定物品页面的 Excel 导入及留货库存页面沿用原结构。指定物品记录继续同步至主明细，策略平均值显示不适用原因。

## 可留货库存（2026-10-15）

- `#stayInventory` 仅展示可留货库存，取消货盘 Tab 和严选库存展示。页面支持查询、查看详情和导出，不提供直接锁货操作。
- 基础字段以 2026-10-14 附件的 56 列为准；列表按确认的 56 项顺序排列，结算价、预估售价位于关联策略之前，价格更新时间追加在末尾；导出保持附件顺序。筛选对齐截图 12 项：型号、内存、颜色、运营中心、库存状态、海外等级、最新看图成色、商品码、物品编码、质检报告编号、货源主体、海外购买渠道。
- 9 项下拉筛选均支持勾选多选，显示已选值或数量，支持清空、外部点击和 Esc 收起；同字段按“或”、不同字段按“且”组合。商品码、物品编码、质检报告编号为单值精确查询。“海外购买渠道”位于普通筛选网格，按钮栏仅保留查询、重置、导出。
- Excel 导出当前筛选后的全部可留货库存记录，追加数据来源（固定为“可留货库存”）、价格更新时间。
- 海外结算价在列表沿用附件列名“结算价”，额外显示价格更新时间；无价格显示“—”，不以 0 代替。库存快照时间与价格更新时间分别展示。
- 已确认的价格规则：BI 只同步库存属性，不提供价格，同物品编号同步时不清空已存价格；每天 8:00 更新可留货库存结算价，执行留货时再次取价、保存并以最新价格判断。静态页面使用独立价格映射和虚构记录，不调度真实任务、不调用真实接口。
- 已确认的试算口径：使用可留货库存中已保存的结算价，无价格商品跳过；试算不重新取价。严选库存后端取价和策略匹配规则不在本次页面调整范围内。
- 验证：`JSDOM_MODULE=/path/to/jsdom node tests/retention-inventory.dom.cjs`，覆盖整页加载、字段、筛选、单货盘展示、详情、Excel、分页及原有留货结果/明细回归。

## 策略弹窗与库存价格试算（2026-10-15）

- 新建、编辑策略在弹窗内完成，试算图位于“留货目标与价格”正上方。列表“价格试算”进入对应策略的同一弹窗；关闭和取消不保存更改。
- 图表按单品已保存的结算价显示价格以内的累计库存数量，支持拖动、键盘滑块和精确价格输入。无价格商品单独计数并跳过；不按目标数量截断。试算不取价、不执行留货。
- 按型号、内存、海外等级、海外购买渠道匹配演示预估售价；多个渠道取最低值。预估售价仅作参考线，超过参考价仍可拖动或输入价格。所选渠道售价缺失时不取部分渠道的最低值，数量仍可试算，但不能自动应用。
- 点击“应用价格”：试算价不高于参考价时，将基准价填为试算价、最高价填为参考价；高于参考价时只显示“超出预估售价请确认后手动输入”，保留原字段值。手动输入保留，最高价须不低于基准价。
- 应用价格仅修改当前表单，保存后更新该策略的演示列表；编辑已有策略保持 ID 和状态。新建、编辑结果仅保存在当前页面内存，刷新恢复演示数据，不会创建生产策略。
- `strategy-editor.js` 使用专门的演示库存快照与 CNY 售价目录，按当前货品范围、海外等级、渠道、颜色及可售状态圈选；与库存列表的 24 条占位示例相互独立，不能视为实际接口结果或生产跨页面数据一致性验证。
- 验证：`JSDOM_MODULE=/path/to/jsdom node tests/retention-price-trial.dom.cjs`，覆盖价格边界、缺价、多渠道最低价、参考价以上拖动、自动回填和超价提示、上下文切换、弹窗新建编辑与取消保存。
